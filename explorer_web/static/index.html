        ModeMeaningExample
        literal Exact substring. Paste anything — no special characters, no escaping. Replacement is also verbatim. (disambiguation) matches those exact 16 characters, parens included.
        glob (*) Exact substring, except * = the shortest stretch of anything within one line. Never crosses a newline. Multiple *s fine. Need a real asterisk? Use literal mode. Start of the match*end of the match
        ✓ "… Start of the match. Stuff in the middle. Finally, end of the match."
        ✗ "… Start of the match. The end of the line." (second part missing on that line)
        A trailing * adds nothing — combine with line to take the rest of the line. Every non-* character is strict, spaces included: A * B demands literal spaces (so A B single-spaced fails — the two pattern spaces need two characters); use A*B for "whatever's between, including nothing".
        regex Full Python regex. Replacement may use backrefs (\1). Patterns are stress-tested at save — pathological backtracking is rejected. \(\s*[;,]?\s*\) matches empty parens like ( ), (; ), (,).
        line ☐ Works with any mode: the match selects its entire line, newline included. Blank replacement = delete the line. glob Category:* + line ☑ deletes every line containing Category:.
        All modes match case-sensitively unless the row's aA box is checked (regex can also inline (?i)). The \n box makes literal/glob interpret \n \t \\ in pattern and replacement (e.g. literal >>>>>\n = those characters followed immediately by a newline); off = every character verbatim. Scrubs run in list order on surviving records only; order matters (a rewrite can expose patterns for LATER scrubs — put cleanup scrubs last, or enable "run to fixpoint" for chains that feed earlier rules). Blank replacement always means "delete the match". Preview before composing — the diffs are the ground truth.
